# ЛР 3.2 — Кубический сплайн (вариант 3)

## Постановка

Даны точки из `data/spline.txt` (в файле **только точки**, никакой функции):

| x | y |
|------|---------|
| 0.0 | 0.00000 |
| 0.9 | 0.36892 |
| 1.8 | 0.85408 |
| 2.7 | 1.78560 |
| 3.6 | 6.31380 |

Требуется: построить кубический сплайн с граничными условиями S″(x₀) = S″(x₄) = 0
(«естественный» сплайн), вычислить S(x*), x* = 1.5.

---

## Идея метода

На каждом интервале [xᵢ₋₁, xᵢ] — своя кубическая парабола. Отрезок i (i = 1..4):

```
Sᵢ(x) = aᵢ + bᵢ·t + cᵢ·t² + dᵢ·t³,      t = x − xᵢ₋₁
```

Кубика — минимальная степень, при которой во внутренних узлах можно состыковать
полиномы с непрерывными S′ и S″: стыки гладкие.

### Счёт условий (их столько же, сколько неизвестных)

4 интервала × 4 коэффициента = **16 неизвестных**.

- Sᵢ проходит через оба конца своего отрезка — 2·4 = 8 условий;
- непрерывность S′ в трёх внутренних узлах — 3;
- непрерывность S″ в трёх внутренних узлах — 3;
- граничные S″(x₀) = S″(x₄) = 0 — 2.

Итого 16 — система имеет единственное решение.

### Ключевое упрощение

Систему 16×16 не решаем. Используем замену:

```
cₖ = S″(xₖ) / 2,      k = 0..4
```

Тогда непрерывность S″ в узлах выполняется сама собой (слева и справа от узла
S″ совпадает с 2cₖ), и фактически неизвестные — пять чисел c₀..c₄.
Непрерывность S′ в внутреннем узле i (i = 1..3) даёт уравнение:

```
hᵢ₋₁·cᵢ₋₁ + 2(hᵢ₋₁ + hᵢ)·cᵢ + hᵢ·cᵢ₊₁
        = 6·( (yᵢ₊₁ − yᵢ)/hᵢ − (yᵢ − yᵢ₋₁)/hᵢ₋₁ )
```

где  hᵢ = xᵢ₊₁ − xᵢ  (шаг, у нас все шаги = 0.9).

Граничные условия дают  c₀ = c₄ = 0.

Остаётся **трёхдиагональная система 3×3** на c₁, c₂, c₃ (в общем случае (n−2)×(n−2)):

```
│ 2(h₀+h₁)   h₁          0       │ │c₁│   │ 6((y₂−y₁)/h₁ − (y₁−y₀)/h₀) │
│    h₁    2(h₁+h₂)     h₂       │ │c₂│ = │ 6((y₃−y₂)/h₂ − (y₂−y₁)/h₁) │
│    0        h₂     2(h₂+h₃)    │ │c₃│   │ 6((y₄−y₃)/h₃ − (y₃−y₂)/h₂) │
```

Решается прогонкой Томаса — тот же алгоритм, что в задаче 1.2 lab1
(`tridiagonal/tridiagonal.go` переиспользован).

### Остальные коэффициенты (явные формулы, без систем)

```
aᵢ = yᵢ₋₁
bᵢ = (yᵢ − yᵢ₋₁)/hᵢ₋₁ − hᵢ₋₁·(cᵢ + 2cᵢ₋₁)/3
dᵢ = (cᵢ − cᵢ₋₁)/(3hᵢ₋₁)
```

Важно: в `Piece` поле `C` хранит именно **cᵢ₋₁** (левый конец отрезка),
потому что полином записан через локальную координату t от левого конца,
а S″(xᵢ₋₁ + 0) = 2cᵢ₋₁.

## Вопросы с защиты (короткие ответы)

- **Почему сплайн — кубический?** Минимальная степень, дающая непрерывность
  второй производной. Квадратика не даёт красоты стыков, четвёртая — лишняя
  степень свободы потребовала бы ещё одного условия.
- **Что такое «естественный» сплайн?** С нулевыми вторыми производными на
  краях S″(x₀) = S″(xₙ) = 0 — так ставится в ТЗ.
- **Как получилось трёхдиагональное уравнение?** Из приравнивания S′ слева и
  справа во внутреннем узле; всё, кроме c, выражается через известные y, h.
- **Почему bᵢ ≠ простой разделённой разности?** Потому что b получена из
  непрерывности S′ с учётом вклада слагаемых c·t² и d·t³.
- **Чем сплайн лучше интерполяционного многочлена Ньютона из 3.1?»** Меньшее
  осциллирование: многочлен с 5 узлами колеблется между узлами (феномен Рунге
  при росте n), сплайн — piecewise-кубики с непрерывной 2-й производной
  колеблются слабее.
