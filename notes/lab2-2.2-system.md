# ЛР 2.2 — Система нелинейных уравнений (вариант 3, a = 4)

## Постановка

Из `data/system.txt` (в файле не хардкод): `n eps x0` = `2 0.0001 5 1`.

Система (вариант 3, a = 4):

```
{ F1(x) ≡ (x1² + 16)·x2 − 64 = 0          — рациональное
{ F2(x) ≡ (x1 − 2)² + (x2 − 2)² − 16 = 0  — окружность радиуса 4, центр (2, 2)
```

Геометрия: решения — точки пересечения гиперболы x2 = 64/(x1²+16) с окружностью.
Их **два**:

- (5.9293, 1.2511) — правая нижняя, к ней ведут оба метода (x0 = (5, 1));
- (−1.7663, 3.3473) — левая верхняя (второе решение, ни к одному методу при
  стартовой точке x0 = (5, 1) не приходит).

Требование ТЗ: решить методами простых итераций и Ньютона, ε = 10⁻⁴, сравнить
скорость сходимости.

## Метод простой итерации (SI)

### Сведение к x = φ(x)

Каждую переменную выражаем **из своего** уравнения:

```
из окружности:      x1 = 2 + √(16 − (x2 − 2)²)    — ветка с ПЛЮСОМ
из рационального:   x2 = 64/(x1² + 16)
```

В коде: `funcs/funcs.go:39–51` (`PhiSystem`), a/2 = 2, a³ = 64.

- Плюс-ветка — осознанный выбор: она смещает к решению (5.9293, 1.2511);
  минус-ветка дала бы второе решение (−1.7663, 3.3473).
- Если a² − (x2−2)² < 0 — корень из отрицательного: φ возвращает nil (funcs.go:41–43).
- Схема типа **Зейделя**: x1 считается по старому x2, а x2 — уже по
  НОВОМУ x1 (funcs.go:45–46, x1 подставлен сразу). Не «одновременная» замена.

x2 = 64/(34.492+16) = 1.26753 ✓ (именно с новым x1, не со старым x0 = 5!).

### Сходимость SI: условие и константа q

«Сдвиг»-критерия сходимости: вектор φ — сжимающее отображение, т.е. его
якобиан по норме меньше 1 в окрестности корня:

```
Φ′(x) = | ∂φ1/∂x1   ∂φ1/∂x2 |   =   |         0          −(x2−2)/√(16−(x2−2)²) |
        | ∂φ2/∂x1   ∂φ2/∂x2 |       | −64·2x1/(x1²+16)²              0 |
```

Диагональ нулевая, потому что мы выражали каждую переменную из СВОЕГО
уравнения: φ1 содержит только x2, φ2 — только x1 (производная по «чужой»
переменной равна 0).

q = max ‖Φ′(x)‖∞ ≈ max(0.19, 0.29) ≈ 0.29 < 1 → сжимающее, сходится.

Сходимость линейная со знаменателем q; оценка ошибки через разности:

```
‖x* − x⁽ᵏ⁾‖ ≤ q/(1−q) · ‖x⁽ᵏ⁺¹⁾ − x⁽ᵏ⁾‖     при q = 0.29: ≈ 0.41·‖Δ‖
```

Бонус для защиты: из-за нулевой диагонали и «зейделевской» композиции
фактическое сжатие за полный ход ~ 0.19·0.29 ≈ 0.055 — поэтому хватило 5
итераций.

## Метод Ньютона

### Вывод формулы

Линеаризуем F вокруг x⁽ᵏ⁾ и требуем нуля:

```
F(x + δ) ≈ F(x) + J·δ = 0     →     J·δ = −F(x)     →     x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ + δ
```

В коде (system.go:54–59) знак «перевёрнут» через решение J·Δ = **+F(x)** и
вычитание: Δ = −δ, x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ − Δ. Одна и та же формула:
x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ − J⁻¹(x⁽ᵏ⁾)·F(x⁽ᵏ⁾).

### Якобиан — четыре частные производные (выводятся, а не «захардкожены»)

```
F1 = (x1² + a²)·x2 − a³:
    ∂F1/∂x1 = 2·x1·x2        (произведение: по x1 — 2x1, x2 — множитель)
    ∂F1/∂x2 = x1² + a²       (вторая скобка целиком)

F2 = (x1−a/2)² + (x2−a/2)² − a²:
    ∂F2/∂x1 = 2(x1 − a/2)    (остаток квадрата)
    ∂F2/∂x2 = 2(x2 − a/2)

J(x) = | 2x1x2       x1²+a²   |
       | 2(x1−2)     2(x2−2)  |        funcs.go:60–67
```

### Шаг — через LU, не через обращение матрицы

На каждой итерации решается система J(x⁽ᵏ⁾)·Δ = F(x⁽ᵏ⁾) пакетом LU из lab1
(system.go:54, `lu.Solve(j, fx)`). Явно J⁻¹ не вычисляется — дороже и
численнее хуже. Вырожденность ловится ошибкой LU (system.go:55–57).

### Таблица итераций (реальные данные, x0 = (5, 1))

## Критерий остановки и нормы

Оба метода (конвенция лаб, везде единая):

```
‖x⁽ᵏ⁺¹⁾ − x⁽ᵏ⁾‖∞ = max(|Δx1|, |Δx2|) < ε = 10⁻⁴
```

- Норма-максимум нужна, чтобы свести вектор к числу, и гарантирует: каждая
 координата сдвинулась меньше ε. Сравнение вектора с числом напрямую невозможно —
 поэтому норма.
- У SI на шаге нет F(x) → в Step поле Fx = NaN (system.go:33). У Ньютона F
 вычисляется по необходимости (без неё не решить J·Δ = F), поэтому Fx — живая
 невязка.
- Малая ‖Δx‖ при q < 1 честно отражает близость к корню:
 ‖x* − x⁽ᵏ⁾‖ ≤ q/(1−q)·‖Δ‖.

## Вопросы с защиты (короткие ответы)

- **Система?** Пункт над, две кривые, две точки пересечения.
- **φ?** x1 из окружности (плюс-ветка), x2 из рационального; композиция типа Зейделя.
- **Почему SI сходится?** q = 0.29 < 1 (посчитать производные устно).
- **Критерий остановки?** ‖·‖∞ разности соседних итераций < 10⁻⁴.
- **Формула Ньютона?** Вывод через линеаризацию; J·Δ = F,
  x − Δ; почему LU, а не обращение.
- **Откуда J?** Четыре частные производные — выводит их в уме дифференцированием.
- **Почему Ньютон быстрее?** Квадратичная vs линейная; привести ‖Δ‖ из таблиц.
- **Когда Ньютон падает?** J вырождена (LU error), выход из области определения,
  плохой x0.
- **Входные данные?** Из data/system.txt, не hardcoded.
- **F(x) у SI в таблице?** NaN — метод F не использует.
