# Лабораторная работа № 4 — вариант 3

В этом файле приведены только задачи № 3 из исходных документов. Нумерация заданий сохранена по именам файлов: `P_4_1.doc` — задача Коши (4.1), `P_4_2.doc` — краевая задача (4.2).

## 4.1. Задача Коши — `P_4_1.doc`, вариант 3

**Дифференциальное уравнение:**

\[
y'' - 2y - 4x^2 e^{x^2} = 0.
\]

**Начальные условия:**

\[
y(0)=3, \qquad y'(0)=0.
\]

**Отрезок и шаг сетки:**

\[
x\in[0,1], \qquad h=0.1.
\]

**Точное решение:**

\[
y(x)=e^{x^2}+e^{x\sqrt{2}}+e^{-x\sqrt{2}}.
\]

Для этой задачи требуется реализовать методы Эйлера, Рунге — Кутты и Адамса 4-го порядка и оценить погрешность методом Рунге — Ромберга и сравнением с точным решением.

## 4.2. Краевая задача — `P_4_2.doc`, вариант 3

**Дифференциальное уравнение:**

\[
x^2(x+1)y''-2y=0.
\]

**Граничные условия:**

\[
y'(1)=-1, \qquad 2y(2)-4y'(2)=4.
\]

Граничные условия заданы в точках 1 и 2, поэтому отрезок задачи: \(x\in[1,2]\). В исходном файле шаг сетки для этой задачи отдельно не указан.

**Точное решение:**

\[
y(x)=1+\frac{1}{x}.
\]

Для этой задачи требуется реализовать метод стрельбы и конечно-разностный метод и оценить погрешность методом Рунге — Ромберга и сравнением с точным решением.
