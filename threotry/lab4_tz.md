# Лабораторная работа № 4 — техническое задание

В работе предусмотрены две части: решение задачи Коши для ОДУ второго порядка (задание **4.1**, исходный файл `P_4_1.doc`) и решение краевой задачи для ОДУ второго порядка (задание **4.2**, исходный файл `P_4_2.doc`). Требования этих частей разделены ниже.

## 4.1. Численное решение задачи Коши

1. Реализовать в виде программ следующие численные методы:
   - метод Эйлера;
   - метод Рунге — Кутты;
   - метод Адамса 4-го порядка.
2. Шаг сетки `h` должен задаваться как входные данные.
3. С помощью разработанного программного обеспечения решить заданную задачу Коши для ОДУ второго порядка на указанном отрезке.
4. Оценить погрешность численного решения:
   - с использованием метода Рунге — Ромберга;
   - сравнением численного решения с точным решением, приведённым в таблице варианта.

## 4.2. Численное решение краевой задачи

1. Реализовать в виде программ следующие методы решения краевой задачи для ОДУ:
   - метод стрельбы;
   - конечно-разностный метод.
2. С помощью разработанного программного обеспечения решить заданную краевую задачу для ОДУ второго порядка на указанном отрезке.
3. Оценить погрешность численного решения:
   - с использованием метода Рунге — Ромберга;
   - сравнением численного решения с точным решением, приведённым в таблице варианта.

## Исходные данные

Конкретное дифференциальное уравнение, условия задачи, отрезок интегрирования и точное решение берутся из строки **варианта № 3** соответствующего исходного файла. Задания 4.1 и 4.2 относятся к разным исходным файлам и не должны подменять друг друга:

- `P_4_1.doc` — задание 4.1, задача Коши;
- `P_4_2.doc` — задание 4.2, краевая задача.
