# Контекст: Лабораторная работа №3 (Вычислительная математика)

## 3.1. Интерполяция (Лагранж и Ньютон)
**Задача:** Реализовать методы интерполяции Лагранжа и Ньютона.
**Требования к выводу:**
1. Исходные узлы ($x_i, y_i$).
2. Аналитический вид многочлена Лагранжа.
3. Таблица разделённых разностей.
4. Аналитический вид многочлена Ньютона.
5. Значения $L(x^*)$ и $N(x^*)$.
6. Точное значение $f(x^*)$.
7. Абсолютная погрешность интерполяции.
8. Разность $|L(x^*) - N(x^*)|$.
**Визуализация:** Общий график (исходная функция, $L(x)$, $N(x)$, узлы интерполяции, точка $x^*$).

## 3.2. Кубический сплайн
**Требования к выводу:**
1. Исходные узлы ($x_i, y_i$).
2. Коэффициенты сплайна ($a_i, b_i, c_i, d_i$) для каждого участка.
3. Границы интервалов действия каждого многочлена.
4. Значение сплайна $S(x^*)$ и номер содержащего его интервала.
5. Результат проверки прохождения сплайна через исходные узлы.
6. Значения вторых производных на концах интервала (проверка граничных условий).
**Визуализация:** График (исходные узлы, все участки сплайна, точка $(x^*, S(x^*))$).

## 3.3. Метод наименьших квадратов (МНК)
**Задача:** Построить аппроксимирующие многочлены $P_1(x), P_2(x), P_3(x)$.
**Требования к выводу:**
1. Коэффициенты и явный вид многочленов $P_1(x), P_2(x), P_3(x)$.
2. Значения MSE (среднеквадратичной ошибки) для каждого многочлена по всем точкам.
3. Сравнение MSE и указание наилучшего многочлена.
**Визуализация:** Общий график (исходные точки, $P_1(x), P_2(x), P_3(x)$).

## 3.4. Численное дифференцирование
**Требования к выводу:**
1. Исходная таблица значений функции.
2. Целевая точка вычисления производной.
3. Узлы таблицы, использованные в расчёте.
4. Значение первой производной.
5. Значение второй производной.

## 3.5. Численное интегрирование
**Методы:** Левые/правые/средние прямоугольники, трапеции, Симпсон. Уточнение по Рунге-Ромбергу.
**Требования к выводу (в виде таблицы):**
Для каждого метода:
1. Значения интеграла при шагах $h_1$ и $h_2$.
2. Порядок точности метода $p$.
3. Уточнённое значение (Рунге-Ромберг).
4. Оценка погрешности результата для шага $h_2$.
**Дополнительно (если интеграл берётся аналитически):**
1. Точное значение интеграла.
2. Абсолютные погрешности каждого численного метода.
3. Указание наиболее точного метода.
**Визуализация:** Не требуется.
